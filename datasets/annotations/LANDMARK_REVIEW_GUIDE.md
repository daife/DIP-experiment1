# 28 点人工复核交接说明

## 数量与范围

原始 PDF 的步骤六没有规定最低张数；明确要求固定 28 点顺序、遮挡点 `visibility=0`、预标注后人工修正。配套详细说明还要求测试集人工检查。本地已预标注 **320 张：train 240、validation 32、test 48**。这是实践规模建议，不是规格门槛。完整样本清单、图片校验值和模型来源见 `review_sets/landmark320/review_set.json`。最终回归质量仍须以人工校正后的 validation NME 和可视化误差判断。

## 输入与启动

- 输入：`review_sets/landmark320/annotations.jsonl`；其中 64 张来自原短程基准，256 张来自固定补充抽样。图像由 `image_id` 定位到本地 `datasets/raw/anime256/`，请勿移动源图。图片和原始压缩包留在本地忽略目录，不进入 Git。
- 规范与编号图：`landmark28_schema.json`、`../../results/landmark28_index.png`。
- 在项目根目录运行：

```powershell
.venv\Scripts\python.exe scripts\review_landmarks.py
```

浏览器会打开 `http://127.0.0.1:8765/`。结束时在运行命令的终端按 `Ctrl+C`。再次运行可从已保存记录继续。若端口已占用，可用 `--port 8767` 等指定另一端口。

## 每张图的操作

1. 参考编号图，从 0 到 27 检查点是否落在对应轮廓、眉、眼、鼻、嘴的位置。只拖动看得见但标错位置的点；不要依据模型 `confidence` 决定可见性。
2. 选中被遮挡/裁掉/无法直接观察的点按 **H** 标为 0；其余没有单独标记的点，在保存时自动记为可见 1。误标为 0 后可按 **V** 改回 1。**即使自动点恰好落在被遮挡位置的合理推测处，也标 0。若该点被遮挡且自动位置明显不合理，也标 0，不要把猜测位置拖成所谓真值。**遮挡点坐标保留作占位，后续训练和 NME 会屏蔽。
3. 若整图无可可靠标注的人脸，使用“整图不可标”，并在备注写清原因；该记录后续应排除出训练和 NME。
4. 检查完本图后点击“保存并下一张”或按 **S**。普通图片不用填写任何文字；整图不可标时才需在备注中写原因。黄色为自动点（保存时默认可见），绿色为已标可见，灰色为遮挡。保存后工具记录时间、修正过的点号和遮挡点号。
5. 优先仔细看 `anime256:270509-16840.jpg`：短程基准中这张的 4、9、10、19 号点预测越界。320 张中共发现 6 个自动点越界，位置和原因均需人工逐图判断；其它图也需逐点看。
