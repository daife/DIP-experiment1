# 28 点人工复核交接说明

## 数量与范围

原始 PDF 的步骤六没有规定最低张数；明确要求固定 28 点顺序、遮挡点 `visibility=0`、预标注后人工修正。配套详细说明还要求测试集人工检查。本地已预标注 **320 张：train 240、validation 32、test 48**。这是实践规模建议，不是规格门槛。完整样本清单、图片校验值和模型来源见 `review_sets/landmark320/review_set.json`。最终回归质量仍须以人工校正后的 validation NME 和可视化误差判断。

## 输入与启动

- 输入：`review_sets/landmark320/annotations.jsonl`；其中 64 张来自原短程基准，256 张来自固定补充抽样。复核图片随仓库保存在 `review_sets/landmark320/images/`，清单中的 SHA-256 用于校验文件完整性；原始数据目录仍可作为本地回退来源。
- 规范与编号图：`landmark28_schema.json`、`../../results/landmark28_index.png`。
- 在项目根目录运行：

```powershell
.venv\Scripts\python.exe scripts\review_landmarks.py
```

浏览器会打开 `http://127.0.0.1:8765/`。结束时在运行命令的终端按 `Ctrl+C`。再次运行可从已保存记录继续。若端口已占用，可用 `--port 8767` 等指定另一端口。

## 每张图的操作

1. 参考编号图，从 0 到 27 检查点是否落在对应轮廓、眉、眼、鼻、嘴的位置。可见但坐标偏离的点，拖到实际位置；不要依据模型 `confidence` 决定可见性或坐标质量。
2. 被头发等遮挡、但可根据另一侧五官和脸部结构合理推定位置的点，先检查坐标；有偏离就拖到**合理推定位置**，再按 **H** 标为 `visibility=0`、`coordinate_quality=reliable_estimate`。自动点已经合理时不用移动，但仍按 H。这里的“可靠”指能给出相对稳定的推定位置，并不宣称遮挡下的真实坐标可直接观察。
3. 被遮挡、裁掉或出画，且无法可靠推定位置的点按 **U** 标为 `visibility=0`、`coordinate_quality=uncertain`；这类坐标只是占位，不作为训练目标。误标后可按 **V** 改为可见。剩余未单独标记的点在保存时自动记为可见 1。
4. 若整图无可可靠标注的人脸，使用“整图不可标”，并在备注写清原因；该记录后续应排除出训练和 NME。
5. 检查完本图后点击“保存并下一张”或按 **S**。普通图片不用填写任何文字；整图不可标时才需在备注中写原因。黄色为自动点，绿色为已标可见，灰色为遮挡且位置可推定，红色为位置不可靠。保存后工具记录时间、修正过的点号、遮挡点号及可用推定点号。
6. 优先仔细看 `anime256:270509-16840.jpg`：短程基准中这张的 4、9、10、19 号点预测越界。320 张中共发现 6 个自动点越界，位置和原因均需人工逐图判断；其它图也需逐点看。

## 交还给助手

校正会写入 `datasets/annotations/corrected/landmark28_review320.jsonl`，自动预标注原文件不会改变。完成本批后，发消息说明“320 张人工复核已完成”，并指出有无整图不可标、编号定义疑问或其它异常；无需复制大量坐标。我会验证 JSONL 的 320 个 ID、28 点、可见性、复核元数据及 split，抽查修改和困难样本，再计算平均形状并训练回归器。未完成全批也可报告已完成数量，以便先检查流程。

训练时在固定 split 和相同特征、随机种子下比较两种回归损失：①所有 `visibility=0` 坐标均屏蔽；②纳入 `coordinate_quality=reliable_estimate` 的遮挡点，屏蔽 `uncertain` 点。主要 NME 按 PDF 只统计可见点；另报告可靠推定遮挡点上的误差作为辅助观察，不能称为可直接核验的真值精度。历史复核记录若没有 `coordinate_quality`，先按 `uncertain` 处理，需重新复核才可纳入方案②。

原始图和自动标注保留在本地忽略目录。人工校正文件进入版本管理；不要把原始图复制到可提交的 `results/`。
