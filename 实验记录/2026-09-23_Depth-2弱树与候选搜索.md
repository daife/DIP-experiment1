# 实验记录：步骤四 Depth-2 弱树与候选搜索

- 日期：2026-09-23
- 范围：像素差特征、Depth-2 弱树推理、单棵弱树的随机候选与加权贪心搜索
- 输入：步骤三生成的 11 通道 `uint8` 裁剪，单张形状 `(11, 24, 24)`，批量形状 `(N, 11, 24, 24)`

## 方法

候选特征指定通道 `c` 和两个窗口内坐标 `p1=(x1,y1)`、`p2=(x2,y2)`，取有符号差值 `C[c,y1,x1] - C[c,y2,x2]`，避免 `uint8` 减法溢出。节点在差值小于等于整数阈值时走左分支。弱树有根节点、左右两个子节点和四个实数叶子分数；正分数偏向人脸。

训练时使用固定种子的 NumPy 随机数生成器抽取互不重复的候选特征。对每个根候选，按加权多数分类错误选择阈值；随后在根的左右样本分支分别搜索子节点，最终选择加权错误最小的完整弱树。叶子分数用正负样本权重的对数比值计算，并加微小平滑以处理纯类别或空叶子。输入权重会归一化，因此返回的加权错误在 0 到 1 之间。

实现分别位于 `src/weak_tree.py` 和 `src/weak_tree_training.py`。固定候选池接口便于核对搜索过程，随机候选接口通过 `seed` 保证可复现。

## 验证

运行：

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

共 16 项测试通过。其中弱树相关测试覆盖：负向像素差及坐标顺序、四个叶子和阈值相等边界、单张与批量推理、加权搜索对四个叶子的拟合、样本权重改变最佳阈值、随机候选的去重与复现、非法输入拒绝。

## 当前限制

这里只完成单棵弱树的搜索，尚未实现 AdaBoost 权重更新、多个弱树组合、Cascade Stage 阈值或困难负样本挖掘。步骤三正负样本仍在人工复核，因此没有使用未复核数据训练正式模型，也没有报告真实数据上的检测指标。
